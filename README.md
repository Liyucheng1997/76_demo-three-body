# 三体系统模拟器 · Three-Body Simulator

一个基于 **Three.js** 的三体问题可视化模拟器，灵感来自刘慈欣《三体》。三颗恒星在彼此引力下做真实的混沌运动，一颗行星（三体星）夹在其中，承受着永不重复的环境剧变——并据此判定**恒纪元 / 乱纪元**。

> 单文件、零依赖（Three.js 通过 CDN 加载），用浏览器打开 `index.html` 即可运行。

## ✨ 特性

### 真实的三体物理引擎
- 三颗恒星按**牛顿万有引力**相互作用，**速度 Verlet 积分** + 每帧 8 子步，保证混沌系统的数值稳定。
- 引入**软化长度（softening）**，避免近距离引力发散导致系统崩溃。
- 用**位力定理（virial theorem）**标定初速度（位力比 `Q = 2·KE/|PE|` ≈ 0.4~0.55），保证系统**总能量为负、被引力束缚**，三星持续缠绕绕转而非四散飞走。
- 自动消除质心漂移，系统稳定停在画面中心。
- 体现三体问题的本质：**无解析解、对初始条件极度敏感**，每次重置轨道永不重复。

### 致敬《三体》游戏的行星设定
- 行星实时接收三颗恒星的总辐射通量 `F = Σ 光度 / 距离²`，按 `T ∝ F^(1/4)` 反推**表面温度**。
- 据此判定**恒纪元 / 乱纪元**：温度落在适居带且近期波动小 → 恒纪元，否则乱纪元。
- 还原原著现象：**三日凌空 · 双日临空 · 严寒长夜 · 飞星不动 · 气候温和**等。
- 行星颜色随温度变化：冰蓝 → 绿（适居）→ 黄褐 → 灼红发光。

## 🚀 运行
直接用现代浏览器打开 `index.html` 即可，无需构建或安装任何依赖。

## 📖 关于三体问题
三体问题指三个天体在引力作用下的运动问题。与可精确求解的二体问题不同，三体问题在一般情况下**没有解析解**，且系统对初始条件极度敏感——这正是「混沌」的典型代表。即使是束缚的三星系统，经过长时间演化也可能**自发抛射出一颗恒星**，这在本模拟器中会真实地发生（状态栏提示「恒星逃逸」）。
