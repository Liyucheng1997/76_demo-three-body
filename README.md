# 三体 · Trisolaris

**高精度三体动力学 × 行星气候 × 文明演化模拟器**

以真实物理单位运行的三星系统：牛顿引力下的混沌轨道、由恒星物理决定的光度与颜色、带热惯性和反馈机制的行星气候，以及在恒纪元与乱纪元交替中兴衰的三体文明。灵感来自刘慈欣《三体》。

**在线体验**：https://liyucheng1997.github.io/76_demo-three-body/

```bash
npm install
npm run dev      # 开发服务器
npm test         # 物理 / 气候 / 模拟回归测试
npm run build    # 生产构建 → dist/
```

## 物理模型

### 1. 引力动力学：`src/physics/nbody.js`

| | v1 | v2 |
|---|---|---|
| 单位 | 无量纲，G = 1 | **AU · M☉ · 年**，G = 4π² |
| 引力 | 带软化长度 0.6（近距离引力被人为削弱） | **纯牛顿引力，无软化** |
| 积分器 | Velocity Verlet，固定步长 | **四阶 Hermite P(EC)²**（Kokubo et al. 1998） |
| 步长 | 固定 | **Aarseth (1985) 自适应判据**：近距离交会自动缩小到所需精度 |
| 碰撞 | 无 | 物理半径判定；恒星合并（动量守恒）、行星被吞没 |
| 精度 | 未知 | 典型相对能量误差 10⁻⁸ ~ 10⁻¹² |

验证（见 `tests/physics.test.js`）：
- 地球绕太阳一年后回到原位，误差 < 10⁻⁶ AU；
- e = 0.9 的开普勒轨道 100 圈后能量误差 < 10⁻⁶，偏心率不漂移；
- **8 字形解**（Chenciner & Montgomery 2000）一个周期后回到初始构型；
- **毕达哥拉斯三体问题**（Burrau 1913）复现 Szebehely & Peters (1967) 的结局：质量 3 的星被抛射，4 与 5 组成双星。该结果在 η ≤ 10⁻³ 时收敛。

### 2. 恒星物理：`src/physics/stellar.js`

由质量单一参数推出全部性质：
- 主序**质光关系**（分段幂律）与**质量-半径关系**；
- 斯特藩-玻尔兹曼定律得到**有效温度**与**光谱型**（如 G2V、K5V）；
- **黑体颜色**：普朗克谱对 CIE 1931 色匹配函数积分 → XYZ → 线性 sRGB。恒星颜色、轨迹颜色、背景星空颜色均由此计算，而非手工指定。

### 3. 轨道分析：`src/physics/orbit.js`

- 密切轨道根数（a, e, i, 周期）；
- **行星轨道分类**：S 型（绕单星）、P 型（环双星）、混沌游荡、未束缚。判据综合束缚能与其余恒星的**潮汐摄动比**；
- **系统层级分析**：识别内双星，用 **Mardling & Aarseth (2001) 稳定判据**判断是否层级稳定；
- **恒星逃逸检测**：相对其余系统能量为正、远离且向外运动。

### 4. 行星气候：`src/climate/ebm.js`

零维能量平衡模型 `C·dT/dt = S(1−α)/4 − OLR(T)`，在 S = S₀ 时标定为 288 K：
- **热惯性**：海洋混合层热容（可调深度），温度滞后于日照变化；
- **冰-反照率反馈**：可进入雪球态，且存在**双稳态与滞后**；
- **失控温室**：OLR 饱和于 Simpson–Nakajima 极限（≈ 282 W/m²），辐照超过约 1.2 S₀ 后海洋蒸发、温度跃升；
- 气候在**每个积分步**内更新，近距离交会期间的辐照尖峰不会因播放速度而漏掉。

### 5. 纪元、天象与文明：`src/climate/era.js` · `civilization.js`

- **恒纪元**：表面温度持续处于 0–45 ℃ 且变化平缓（带迟滞区间）；
- **天象**：由行星上看到的各太阳**视直径与辐照**判定：三日凌空、双日临空、三颗飞星（视直径 < 太阳的 1/10）等；
- **文明**：恒纪元中发展（石器 → 星际时代），乱纪元脱水，烈日 / 严寒 / 行星毁灭时消亡，下一个恒纪元中新文明诞生。

### 6. 混沌与可预测性：`src/sim/chaos.js` · `forecast.js`

- **最大李雅普诺夫指数**：Benettin 影子轨道重正化法；
- **MEGNO 指标**（Cincotta & Simó 2000）：规则运动 ⟨Y⟩ → 2，混沌运动线性增长（8 字形 ≈ 1.96，随机三体世界持续增大）；
- **孪生宇宙**：初始仅差 10⁻⁶ AU 的平行系统，直观展示蝴蝶效应；
- **集合预报（智子预测）**：在 Web Worker 中对 16 个带观测误差的成员独立积分动力学 + 气候，给出温度 10–90% 区间、恒纪元概率、可预报时长，以及下一次纪元转换的时间。

## 场景

| 场景 | 说明 |
|---|---|
| 三体世界（随机混沌） | 非层级三星 + 宜居带行星；种子可复现、可分享（URL `#preset=trisolaris&seed=…`） |
| 半人马座 α（真实数据） | α Cen A/B 真实轨道（a = 23.3 AU，e = 0.52）+ 比邻星 |
| 环双星世界 | 紧密双星 + P 型行星 + 远处第三星，层级稳定 |
| 8 字形 / 蝴蝶 I / 飞蛾 I | 经典与新发现的周期解（后两者不稳定） |
| 拉格朗日等边三角形 | 等质量时不稳定，数十周期后瓦解 |
| 毕达哥拉斯三体问题 | 积分器精度的经典考验 |

## 可视化

- HDR 渲染 + 辉光 + ACES 色调映射，对数深度缓冲（同屏显示 0.001 AU 到 10⁴ AU）；
- 恒星着色器：米粒组织、临边昏暗与临边变红、冷星黑子；
- 行星着色器：程序化大陆，冰盖 / 海洋 / 植被 / 熔岩随温度变化，三光源照明，夜面城市灯光随文明发展点亮；
- **宜居带辐照场**：在轨道平面实时计算 Σ L/d²，按 Kopparapu et al. (2013) 边界着色；
- 行星**密切轨道**、渐隐轨迹、参考网格、行星天空投影图；
- 温度 / 辐照时间序列（含集合预报带）与纪事日志。

> 天体尺寸经放大显示（真实比例下恒星在 AU 尺度上只是一个点），碰撞判定使用真实物理半径。
